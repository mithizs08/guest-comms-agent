# Guest Comms Agent

An AI guest communications agent for a Sydney short-term rental business (work in progress).

## Data attribution

Property data is derived from [Inside Airbnb](https://insideairbnb.com) (Sydney, scraped June 2026),
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Listings have been filtered,
stripped of host personal information, and supplemented with demo fields marked `"demo_added": true`.
All guest emails and "restricted" values are fictional.
